Mein Projekt: Passwort-Prüfer

Ist mein Passwort schon in einem Datenleck aufgetaucht?

  1. 1

    Passwort wird lokal gehasht (SHA-1)

    5BAA61E4C9B93F3F…
  2. 2

    Nur die ersten 5 Zeichen des Hashs gehen an die „Pwned Passwords“-API von Have I Been Pwned

    /range/5BAA6
  3. 3

    Die API liefert alle bekannten Hash-Enden zu diesem Anfang → Abgleich lokal auf dem eigenen Rechner

    1E4C9B93F3F…:Anzahl

[OK] Das Passwort verlässt nie den Rechner. Prinzip: k-Anonymität
